# Celebrar Convites Digitais — site

Site de uma página da conviteria digital **@celebrarconvitess**.

- `index.html`: conteúdo (início, sobre, serviços, galeria, como funciona, contato)
- `assets/css/style.css`: estilos (cores e fontes no topo, em `:root`)
- `assets/js/main.js`: menu mobile, link do WhatsApp com mensagem, galeria ampliável
- `assets/img/`: logo e convites

Para ver localmente, abra `index.html` no navegador. Para publicar de graça, use GitHub Pages
(Settings → Pages → Branch) ou arraste a pasta para o Netlify Drop.

> As imagens atuais foram recortadas de um print do Instagram e estão em baixa resolução.
> Substitua pelos arquivos originais mantendo os mesmos nomes em `assets/img/`.
